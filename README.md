# NASA APOD Project - Visual Mockup Report

## Design Choices
I designed a clean, structured interface that prioritizes the NASA imagery. By using clear content blocks, the user's eye is drawn immediately to the "Astronomy Picture of the Day."

## Colour and Font Selection
- **Typography:** I selected a clean Sans-Serif font to ensure readability across all device sizes.
- **Colour Palette:** I used a neutral gray for buttons and sidebars to create a modern, professional look that doesn't distract from the colorful space photos.

## Layout and Responsiveness
- **Desktop:** Uses a wide layout with a dedicated sidebar for "Favorite Searches."
- **Tablet/Mobile:** The layout is responsive, stacking the sidebar content underneath the main image to ensure a smooth scrolling experience on smaller screens.

## Usability and UX
The addition of the "Favorite Searches" history list improves usability by allowing users to quickly toggle between previously viewed dates without having to re-use the date picker.
